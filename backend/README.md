# HTTP API SPPR Research

Общий запуск: [корневой README](../README.md).

`tools/run.py` передаёт явные пути к исполняемому ядру R08, исходному плану и папке результатов. Без флага `-engine` доступны только проверка профиля и импорт сводок. OpenAPI: `/api/research/openapi.json`.

API принимает только localhost/loopback Host и разрешённые Origin. Публичное развёртывание и реальное управление оборудованием не предусмотрены.
