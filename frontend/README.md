# Веб-интерфейс SPPR Research

Общий запуск и ограничения: [корневой README](../README.md).

Разработка: `npm ci`, затем `npm run dev`. API запускается из корня через `python tools/run.py --api-only`.

Production-сборка: `npm run build`. Раздел R08 вызывает настоящие вычисления ядра 0.8; разделы F10/E11 пока работают с импортированными данными.
