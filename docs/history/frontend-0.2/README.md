# СППР — интерфейс исследовательского рабочего пространства

Автор проекта: **Адышкин Сергей Сергеевич**. Версия **0.2.0-pre**.

Добавлен интерфейс для нового исследовательского API из `sppr-prototype-back/research`. Это подготовительный слой интеграции с F10/E11, **не полный программный артефакт статьи**: расчётное ядро и replay пока не подключены.

## Разделы

«Обзор и методика» показывает дизайн из статьи и описание семи политик, а не уже выполненные прогоны. «Внешний профиль E11» проверяет CSV, последовательность дат, коды продуктов и байтовый хэш. «Результаты и анализ» работает только с загруженными сводками; пустое хранилище не заполняется демонстрационными числами. «Прежний MVP» сохраняет исходный интерфейс обработки отдельных случаев.

Импорт получает статус «воспроизведение не проверено». Искусственные наборы назначения `software_test` явно обозначаются как инженерные тесты, не научные результаты. Запуск модели и replay отключены и на сервере, и в интерфейсе.

## Запуск

Используйте поддерживаемую версию Node.js, удовлетворяющую `engines` зафиксированной Vite-зависимости. Для этих проверок использовался Node.js 22.16.0. Не копируйте `node_modules` с другой ОС.

```bash
npm ci
npm run typecheck
npm run build
npm run dev
```

Адрес разработки: `http://127.0.0.1:5173`. Порт фиксирован через `--strictPort`, чтобы разрешённый CORS origin не менялся незаметно.

При необходимости скопируйте `.env.example` в `.env`:

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:18080
VITE_RESEARCH_API_BASE_URL=http://127.0.0.1:18081
```

На порту 18081 должен работать новый `research-api`. Для вкладки прежнего MVP отдельно нужен старый PostgreSQL/Gin-сервер на 18080. В исходной конфигурации старого сервера CORS разрешает `http://localhost:5173`; при открытии интерфейса по `127.0.0.1` задайте `FRONTEND_ORIGIN=http://127.0.0.1:5173` в конфигурации старого backend. Для новой исследовательской части оба origin уже разрешены.

Полный API-контракт и смысл данных: `sppr-prototype-back/docs/research-contract.md`; OpenAPI доступен у исследовательского сервера по `/api/research/openapi.json`.

## Проверки этой редакции

Проверка TypeScript выполнена успешно. Браузерные сценарии проверены во внутренней офлайн-сборке с HTTP-мостом к локальному API: штатная навигация Chromium на localhost ограничена средой. Это не проверка обычного браузерного CORS и не production-сборка Vite.

Штатная Vite-сборка в текущей среде **не завершена**: в присланном `node_modules` отсутствует Linux-модуль Rollup; загрузка зависимостей из сети недоступна. До публикации релиза необходимо выполнить `npm ci && npm run build` в нормальной среде с сетью. Обходной тестовый сборщик не включён в репозиторий и не является новым production-инструментом.

Прежняя инструкция: [docs/legacy-frontend.md](docs/legacy-frontend.md).
