## Что проверяли Go-тесты

Полнота F10/E11-сетки, число эпизодов, уникальность ключей, диапазоны повторов, политики, горизонты, парность заявленных внешних лент, обязательные числа, NaN/Inf/отрицательные значения, арифметика суммарной потери; повторяющиеся/неизвестные JSON-ключи и пропущенный нулевой номер повтора; CSV-контракт, даты, окна, коды продуктов и контроль байтового хэша; независимость анализа от порядка строк, исключение normal из первичных контрастов, нулевые разности, отмена анализа; сохранение и повторное чтение исходных байтов, выявление повреждения и символьных ссылок, конкурентный импорт; HTTP-контракты, лимиты, Host/Origin и неизменная блокировка запуска/replay.

Все использованные числовые наборы искусственные, назначения `software_test`. Они созданы только для проверки программы. **Их нельзя включать в результаты статьи или считать новой серией E11.**

## Ограничения браузерной проверки

Штатный Vite не собрался без Linux-зависимости Rollup; загрузить её из сети не удалось. Поэтому для внутренней проверки использована отдельная временная CommonJS-сборка из TypeScript и имеющихся JavaScript-зависимостей. Она не включена в поставку и не заменяет production-сборку Vite.

Управляемый Chromium блокирует обычную навигацию на localhost. Интерфейс отрисован в памяти, а fetch-вызовы направлялись через тестовый мост к реально запущенному локальному Go-серверу. Это позволяет проверить взаимодействие экранов и API, но **не является проверкой обычного браузерного CORS, Vite dev server, nginx или production-развёртывания**. Проверки Host/Origin самого Go-сервера отдельно выполнены HTTP-тестами.

Пройденные сценарии:

1. Загрузка спецификации; кнопки запуска отключены.
2. Корректная структура искусственного CSV не выдаётся за совпадение с исходным E11-профилем.
3. Пустое хранилище не показывает демонстрационные результаты.
4. Импорт полного инженерного набора с видимой тестовой маркировкой.
5. Парный анализ четырёх нулевых контрастов с ожидаемыми нулевыми интервалами.
6. Сохранение импортированного набора после повторной загрузки интерфейса.
7. Мобильная ширина 390 px без горизонтального переполнения документа.

Визуально проверены обзор на desktop/mobile и экран внешнего профиля. Отдельные табличные блоки имеют внутреннюю горизонтальную прокрутку при узком экране.
