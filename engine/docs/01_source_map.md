## Дополнительные инженерные решения этой версии

Это решения новой реализации, не сведения об утраченном коде: стабильная сортировка по идентификаторам; возврат ошибки при неполной входной спецификации; явный JSON-вход; отказ от перезаписи результатов; SHA-256-цепочка статических записей; допуск 1e-12 только при проверке суммы вероятностей; компенсация отрицательного ресурсного остатка лишь в пределах погрешности 1e-12 относительно масштаба сырья.

Риск-ограничение не ослабляется численным допуском. Для постоянной потери расчёт CVaR выполняется через значение вариационной формулы в квантильной точке, чтобы округление хвостового среднего не превратило точное равенство лимиту в ложное превышение.

## Формулы в сохранённом виде

`source_formulas.xml` содержит исходные OMML-фрагменты выбранных формул, включая дроби, индексы и модуль в KPI выполнения плана. `source_extract.json` содержит текст абзацев и таблиц для навигации. Его линейное представление формул не заменяет исходные OMML или DOCX.

Для периодической потери принято вычислимое прочтение P1782:

L(K)=Σ_i w_i [max(l_i−K_i,0)+c_i⁺ max(K_i−h_i,0)]/s_i.

Использованы l=(.95,.95,.7,3), h=(1,1,.9,7), w=(.35,.25,.15,.25), s=(.95,.95,.7,3), c⁺=(0,0,.5,.25). Ниже норма штрафа равна 1. Отдельная проверка смысла нормирования в общем аппарате глав 1–3 остаётся частью научной вычитки; совпадение с утраченной реализацией не установлено.
