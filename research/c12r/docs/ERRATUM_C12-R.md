# Уточнение описания потока проверочных сценариев C12-R

Дата: 1 октября 2026 года. Обнаружено при итоговой проверке комплекта.

В сохранённом до запуска `protocol_c12_final.md` строка о независимой проверке риска
содержит старое смещение `+9999991`, оставшееся от начального драйвера C12.
Эта строка не соответствует фактически выполненному окончательному коду C12-R.
В финальном коде, зафиксированном до расчёта, используется следующая адресация:

```text
base = 1000000 * master_seed + 150000 * profile
validation_seed = base + 70000 + 1024 * day + scenario
```

Именно этот код породил итоговые таблицы и повторную контрольную серию.
Точная адресация также была записана в `history/stream_collision_correction.md`.
Проверку непересечения адресов выполняет `experiment/streams_test.go`.
Независимые проверочные сценарии не использовались для выбора рекомендаций.

Здесь исправляется описательная неточность документа, а не изменяется выполненный
эксперимент. Исходный замороженный протокол сохранён без изменения байтов, чтобы
`source_lock_before_c12_final.sha256` оставался проверяемым. Для воспроизведения
используются замороженный `experiment/run.go` и настоящая адресация, указанная выше.
Ни итоговые числа, ни селектор, ни пороги после этого уточнения не менялись.
