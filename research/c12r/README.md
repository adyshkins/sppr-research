# C12-R: сертифицированный выборочный пересчёт

Самостоятельный Go-модуль вычислительного исследования к статье №4.
Автор: Адышкин Сергей Сергеевич. Дата публикационной сборки: 2026-10-01.

Это новая серия C12-R, а не восстановление F10/E11. Прежние `engine/`,
`backend/`, `frontend/` и их запуск не изменяются. Новый модуль пока не
подключён к веб-интерфейсу: он запускается отдельно из командной строки.
Тексты статьи Word/PDF и личные документы в этот каталог не включены.

## Состав

- `cert/` — четыре селектора, проверка сертификатов и тесты.
- `model/` — двухпродуктовые балансы и библиотека действий.
- `experiment/`, `cmd/study/` — генераторы, задержки и запуск эксперимента.
- `results/c12_final/` — исходные CSV, сводка и 15 снимков C12-R.
- `results/replay_final/` — сохранённые два повторных контрольных блока.
- `results/analysis_final/` — таблицы и численные сводки статьи.
- `results/audit/` — сохранённые отчёты расчётной проверки.
- `docs/` — протокол, происхождение, исправление RNG и исходные хэши.

Историческая первоначальная серия и рукописи остаются в полном архиве
`Статья_4_Код_и_результаты_C12-R.zip`, а не в этой публичной выборке.
Область переноса и контрольные суммы описаны в `docs/publication.md`.

## Проверка без установки Python

Нужны Go 1.23.2 или совместимая более новая версия; Node.js нужен только
для `verify.mjs`. Расчётный Go-модуль использует стандартную библиотеку.
Из этого каталога в PowerShell:

```powershell
$env:GOWORK = 'off'
node verify.mjs
go test ./...
go vet ./...
```

`GOWORK=off` изолирует новый модуль от корневого `go.work` старого приложения.
В Linux/macOS используйте `export GOWORK=off` перед теми же командами.
Для `go test -race ./...` нужны поддерживаемая платформа и C-компилятор;
эта проверка не поддерживается 32-битным Go для Windows.

## Запуск без перезаписи исходных результатов

Быстрый проверочный запуск на Windows (90 коротких эпизодов, не серия статьи):

```powershell
.\run.ps1 -Mode smoke
```

Полная сетка C12-R с новой выходной папкой:

```powershell
.\run.ps1 -Mode full
```

Скрипт создаёт уникальный каталог `results/local-*`, не меняет исторические CSV
и не требует Python. Исходные Go-файлы при упаковке не редактировались.

Для Linux/macOS или ручного запуска из каталога модуля:

```sh
export GOWORK=off
out="results/local-full-$(date +%Y%m%d-%H%M%S)"
test ! -e "$out" || exit 1
go run ./cmd/study -repeats 32 -seed 300001 -days 60 -scenarios 64 -horizon 7 -out "$out"
```

Не запускайте `go run ./cmd/study` без `-out`: исходная программа использует
папку исторических результатов по умолчанию. Для новых запусков нужен новый путь.

## Анализ и границы

`analyze.py` требует Python с numpy и pandas. `audit.py` использует только
стандартную библиотеку Python. Для анализа нового полного расчёта:
`python analyze.py --input results/local-full-... --out results/local-analysis-...`.
Аудит запускайте в отдельной копии модуля: он записывает собственный отчёт в
`results/audit/independent_audit_final.json`. Не подменяйте им сохранённый отчёт.

Первичная серия получена в Linux/amd64 с Go 1.23.2, `GOMAXPROCS=1`.
Межплатформенное побитовое совпадение не гарантируется; поля времени `_ns`
не являются детерминированными. C12-R оценивает сокращение вычислений
при сохранении ответа полного селектора, а не денежный эффект, реальное
экспертное согласование или безопасность промышленного оборудования.
